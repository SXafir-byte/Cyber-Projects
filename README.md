# Cybersecurity Projects

A collection of cybersecurity projects, labs, write-ups, and tools created for learning, research, and authorized testing.

## About

This repository documents my hands-on work across cybersecurity topics such as network security, web application security, scripting, vulnerability analysis, digital forensics, and defensive security.

All projects and testing are performed in legal, authorized environments.

## Projects

| Project | Description | Skills / Tools |
|---|---|---|
| Network Scanner | A tool or lab for discovering hosts, ports, and services on a local test network. | Python, Nmap, Networking |
| Web Security Labs | Notes and demonstrations from intentionally vulnerable web applications. | OWASP Top 10, Burp Suite |
| Log Analysis | Scripts and investigations for detecting suspicious activity in logs. | Python, SIEM, Linux |
| Password Security | Research and lab work focused on password storage, hashing, and defense. | Hashing, Authentication |
| Digital Forensics | File, metadata, or disk-analysis exercises. | Autopsy, Linux, Forensics |
